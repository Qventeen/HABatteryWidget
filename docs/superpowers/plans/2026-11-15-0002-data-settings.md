# Data and settings (0002) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Read exactly the values widget v3 needs (prefix Fill + hand entry), one URL with a plain-HTTP warning, battery state from the current, green theme, units in labels, foldable settings sections; the old widget keeps working without cells.

**Architecture:** One `:app` module, manual DI, pure-Kotlin `domain/` (rules of spec 0001). Data flows HA template → `TemplateResponse` → `BatteryReading` (cache) → `BatteryOverview` → widget and screen. Each task leaves the build green.

**Tech Stack:** Kotlin, Jetpack Compose + Material 3, Glance 1.2, kotlinx.serialization, DataStore, OkHttp, JUnit, Robolectric, mockwebserver3.

**Spec:** `docs/superpowers/specs/2026-11-15-0002-corrections-design.md` (read it first; section numbers below refer to it).

## Global Constraints

- JDK 17: `export JAVA_HOME=/usr/lib/jvm/java-17-openjdk`. Call Gradle as `bash ./gradlew …` from the repo root.
- Unit tests: `bash ./gradlew :app:testDebugUnitTest` (all must pass at the end of every task). Instrumented tests only compile in tasks: `bash ./gradlew :app:compileDebugAndroidTestKotlin`; they run in Task 9.
- `domain/` has no `android.*` import. No new dependencies.
- Every visible text in `res/values/strings.xml` (English) **and** `res/values-uk/strings.xml` (Ukrainian); removed strings go from both. No user text in Kotlin. `NoHardcodedTextTest` stays green.
- The HA token goes only through `TokenStore`; never in logs, errors or UI state.
- The app only reads from HA; never call a service or a control entity.
- Code, comments and docs in English.
- Commits: one per task, header only plus the trailer, style `type(scope): Capitalized imperative summary` (≤ 50 chars), last line `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Stored format may change (spec 5.9); `schemaVersion` stays 1; update `StoredJsonV1Test` in the task that changes the format.

## Review Focus

1. Settings saved by 0.1.0 (`primaryUrl`, `fallbackUrl`, `fallbackPower`, `cells`) must load without a crash and keep the charge/power/current/voltage ids → Task 9 test.
2. Balancing state text from HA in any case or with spaces (`"ON"`, `" on "`) → Task 3 test.
3. A prefix typed with spaces or a trailing `_` (`" bps_bms_ "`) must not give `sensor.bps_bms__…`; upper case (`"BPS_BMS"`) is invalid → Task 3 tests.
4. A blank temperature row on Save must show an error under that row, not drop the row silently → Task 3 test (index) and Task 5 UI.
5. A URL typed with spaces, upper-case scheme or a trailing `/` (`" HTTP://Example.com/ "`) must classify the same as the clean form → Task 4 test.
