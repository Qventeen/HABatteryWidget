# Mode editor (text levels) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The inverter mode is matched by an editable list of "text levels" (texts, name, colour, icon, bell, type), edited in a new Modes section on the Inverter tab.

**Architecture:** A text level is the text counterpart of a 0010 level: a built-in list in code (`DefaultTextLevels`), an own list in settings (`CustomTextLevels`, keyed by `TextValue`), one effective-list check (`TextLevelPicker`). The strip, the mode alert and the notification read the matched item instead of the fixed `InverterMode` table, which is removed. The editor is a draft with Save / Cancel like the level editor.

**Tech Stack:** Kotlin, Jetpack Compose (Material 3), Glance, kotlinx.serialization, JUnit 4 + Robolectric (SDK 34).

**Spec:** `docs/superpowers/specs/2026-11-21-0014-mode-editor-design.md` (approved 2026-11-21). Layout: `docs/design/mode-editor.png`.

## Review Focus

1. **A stored list that is broken or from a later build** (two "other" items, none, a text in two items, an unknown icon or name key): the strip and the alerts must fall back to the built-in list, never crash. Tests: Task 1 `ownLevels_brokenList_isNull`, `textLevelUnknownKeys_readSafely`.
2. **Home Assistant sends the text with other case or spaces** (`" mains "`, `"LINE"`): it must still match its mode. Test: Task 1 `match_trimsAndIgnoresCase`.
3. **The list is edited between two syncs** (a text mapped to another mode, or its mode deleted): the next sync with the same text must not notify. Tests: Task 2 `listEditBetweenSyncs_noAlert`, `deletedModeSameText_noAlert`.
4. **Save is tapped while a text is still typed in "Add text"**: the text must be saved, and a bad one must block the save at its row. Tests: Task 3 `toLevel_includesTypedText`, `saveTextLevels_typedDuplicate_failsAtRow`.
5. **The app language changes**: built-in names are shown in the current language, a user's own name stays as typed. Test: Task 2 `InverterLabelsTest` (`en` and `uk`).
