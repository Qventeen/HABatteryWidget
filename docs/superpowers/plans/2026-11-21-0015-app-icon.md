# App icon and notification icons Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The app gets its own "House of tiles" launcher icon (version A), and each notification shows the glyph of its widget (battery or inverter) instead of a type symbol.

**Architecture:** Resources only, plus one mapping in `AndroidLevelNotifier`: the small icon is chosen by the alert's widget (`LevelValue.INVERTER` and mode alerts → inverter glyph, every other value → battery glyph). The adaptive icon keeps its names and gets a colour background, a vector foreground and a vector monochrome layer.

**Tech Stack:** Android VectorDrawable, adaptive icons (API 26+), Kotlin, JUnit 4 + Robolectric (SDK 34).

**Spec:** `docs/superpowers/specs/2026-11-21-0015-app-icon-design.md` (approved 2026-11-21). Design: canvas row "App icon · v12" (version A, notifications board).

## Global Constraints

- Branch `0015-app-icon` from `epic-widget-improvements`; merge back with a merge commit after the owner's review.

## Review Focus

1. **A battery value other than charge** (cell delta, a temperature): it must show the battery glyph, not the inverter one. Test: Task 1 `post_deltaAlert_showsBatteryGlyph`.
2. **A small icon with colour** shows as a grey square on some phones: both glyphs must use `#FFFFFFFF` only. Check: Task 1 Step 5 grep.
3. **The themed icon** (Android 13+): the tiles must be holes in the monochrome layer, or the house shows as a plain block. Check: Task 2 render.
4. **Launcher masks** (circle, squircle, teardrop): the house must stay inside the 66-dp safe zone. Check: Task 2 render.
5. **A leftover reference** to a deleted drawable or mipmap breaks the build. Check: the gate in Task 2.
