# Widget v4 (0003) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build widget design v4 (SOC ring, two big pack pills, cell and temperature pills, top row with time left, balancing, update time or error, auto-refresh toggle and ↻), mirror it in the app's overview card, and add the display choices, font sizes and the total-capacity sensor.

**Architecture:** One pure-Kotlin `WidgetModel` in `domain/` decides what shows; Glance (widget) and Compose (app card) only draw it. One layout scaled by `s = min(1, w / 360 dp, h / 180 dp)`; the ring is an alpha bitmap arc over a vector track, both tinted with day/night colours.

**Tech Stack:** Kotlin, Glance 1.2 (`glance-appwidget`, `glance-appwidget-testing`), Jetpack Compose + Material 3, kotlinx.serialization, DataStore, JUnit, Robolectric.

**Spec:** `docs/superpowers/specs/2026-11-15-0003-widget-v4-design.md` (read it first; section numbers below refer to it). Visual reference: `docs/design/README.md` and `docs/design/widget-4x2.html` (CSS tokens, icon paths, sizes at 1×).

## Global Constraints

- JDK 17: `export JAVA_HOME=/usr/lib/jvm/java-17-openjdk`. Call Gradle as `bash ./gradlew …` from the repo root.
- Every task ends with `bash ./gradlew :app:testDebugUnitTest :app:compileDebugAndroidTestKotlin` green. Instrumented tests run in Task 10.
- `domain/` has no `android.*` import. No new dependencies.
- Every visible text in `res/values/strings.xml` **and** `res/values-uk/strings.xml`, same commit; removed strings go from both. No user text in Kotlin (`NoHardcodedTextTest`).
- No network in `provideGlance`; the widget renders from the cache and the settings only. The app never writes to HA.
- Glance: at most 10 children per `Row` / `Column` / `Box`; use padding instead of `Spacer` where a row gets full.
- Font size in Glance and Compose: `FontSizes.effective(group, fontScale) × s` (spec 5.4, approach E1).
- Stored format: `schemaVersion` stays 1; update `StoredJsonV1Test` in the task that changes the format.
- Commits: one per task, header only, `type(scope): Capitalized imperative summary` (≤ 50 chars), trailer `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Builder calls (spec 7 leaves these to the builder)

1. **Stored defaults.** 0001 §14 allows only empty defaults "never a real host, entity, interval or capacity". Display choices (`KWH`, `CURRENT`) and font sizes (40 sp …) are not user data, so they keep the spec's design defaults (spec 5.3, 5.12). `architecture.md` gets one line saying so.
2. **Out-of-range interval on toggle.** The app can store `auto = false, interval = 5` (validation runs only when auto is on). Turning auto on from the widget then coerces the interval into 15–1440, so periodic work really starts (spec 5.7 keeps a *valid* interval).
3. **Order in the toggle action:** save → redraw → `scheduler.apply` → `syncNow` (architecture rule: every settings write is followed by a redraw).
4. **App card buttons work:** ↻ runs "Refresh now"; the auto toggle runs the same `ToggleAutoRefresh` as the widget.
5. **Balancing unknown** (`null`): grey icon, description "Balancing unknown".
6. **Glance font cap:** Glance accepts only sp, and Android 14+ scales sp non-linearly; the widget passes `effective × s / fontScale` sp, so the shown size is at most the cap (it can be a little smaller at large system text). The Compose card sets `fontScale = 1` locally and passes `effective × s`, so it is exact.
7. **Time format** stays ICU `MeasureFormat` SHORT (as today): English shows "17 hr, 16 min", "2 days, 7 hr".

## Review Focus

1. Large system font scale (2.0) with every group at its maximum: text stays capped → Task 2 test (`effective`).
2. A launcher gives less than the minimum size (276 × 140 dp): the widget still renders all values → Task 6 test.
3. A stored font size out of range or NaN (old or hand-edited file): clamped on read, no crash → Task 2 test.
4. Toggle on with a stored out-of-range interval (5 min, auto off): periodic work is scheduled with 15 → Task 5 test.
5. Fewer temperature values than configured sensors, or all null with 2+ sensors: "—" pills, plain level, no crash → Task 4 test.

```kotlin
sealed interface WidgetModel {
  enum class EmptyKind { SETUP, NO_DATA }
  enum class Flow { UP, DOWN, NONE }
  sealed interface Temperatures {
    data object None : Temperatures
    data class One(val celsius: Double?, val level: Level) : Temperatures
    data class MaxMin(val max: Double?, val maxLevel: Level, val min: Double?, val minLevel: Level) : Temperatures
  }
  data class Empty(val kind: EmptyKind, val error: SyncError?) : WidgetModel
  data class Data(
    val socPercent: Int, val ringFraction: Float, val ringLevel: Level,
    val underSoc: UnderSoc, val underSocValue: Double?,
    val voltage: Double?, val main: MainValue, val mainValue: Double?, val flow: Flow, val mainLevel: Level,
    val timeLeft: Duration?, val balancing: Boolean?, val updatedAtMillis: Long,
    val error: SyncError?, val refreshing: Boolean, val autoRefresh: Boolean,
    val averageCellVoltage: Double?, val deltaMv: Int?, val deltaLevel: Level,
    val temperatures: Temperatures, val mosfet: Double?, val mosfetLevel: Level,
  ) : WidgetModel
  companion object { fun build(overview: BatteryOverview, settings: Settings): WidgetModel }
}
```

Rules: spec 5.2 table. `Empty(SETUP, null)` when `overview.setupNeeded`; `Empty(NO_DATA, overview.error)` when no reading. `underSocValue`: KWH = Ah left × V / 1000, AH = Ah left, null when an input is missing. `mainValue` = |current| or |power|. `flow` from the current only (±0.1 A, `BatteryMath.IDLE_CURRENT_A`); `mainLevel` UP → OK, DOWN → WARN, NONE → IDLE. `timeLeft = overview.timeRemaining?.duration`. Temperatures by `settings.entities.temperatures.size` (0 → None, 1 → One(first value), ≥ 2 → MaxMin over the non-null values). Null value → level PLAIN.
